FlexiStyle: Unopinionated Modern CSS Base Theme

How building a lightweight, zero-dependency foundation for Drupal 9, 10, and 11 slashed theme asset bloat by over 60% while maintaining WCAG 2.1 AA compliance out of the box.

The Challenge

Traditional Drupal core starter themes (such as Olivero or Classy) inject substantial opinionated CSS and JavaScript. Developers building custom digital products frequently spent days resetting default styles, stripping unwanted layout constraints, and dealing with conflicting utility classes.

Architectural Solution

  • CSS Custom Property Engine: Defined design tokens (colors, spacing, typography scales) directly in CSS variables to allow seamless dark/light mode toggling without compiling tools.
  • Zero JS Overhead: Eliminated all JavaScript runtime dependencies in the base layer, ensuring fast First Contentful Paint (FCP).
  • Clean Twig Templates: Refactored core Drupal markup into minimal, semantic HTML elements, optimizing accessibility and screen reader navigation.
