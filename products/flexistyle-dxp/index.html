FlexiStyle DXP.

Sleek, modern theme built on FlexiStyle Bootstrap with a minimalist black-and-white UI suited for business sites and digital experience platforms.

Details

Built on FlexiStyle Bootstrap and compatible with Drupal 9, 10 and 11. Development is supported by Valuebound.

FlexiStyle DXP is a sleek, modern Drupal theme built on the FlexiStyle Bootstrap base theme. Its minimalist black-and-white UI suits business sites, digital experience platforms (DXP) and portfolios, with a clean, responsive and accessible design.

Live Demo

See the theme in action at digitalexperience.live, the project’s home page and demonstration site.

Visit digitalexperience.live ↗ Drupal.org Project Page ↗

Installation

  1. Install the theme with Composer.
  2. Go to Appearance, find FlexiStyle DXP, then click Enable and set default.
  3. Open Appearance → Settings → FlexiStyle DXP to customize layout, typography and other settings.
composer require 'drupal/flexistyle_dxp:^1.0'

Configuration

  • Navigate to Appearance → Settings → FlexiStyle DXP and customize the layout, typography and other settings.
  • Pick system fonts, Google Fonts or icon fonts (Font Awesome, Bootstrap Icons, Google Material Icons).
  • Add custom body classes for advanced styling. Use predefined layouts or build your own with the Drupal Layout Builder.

Features

  • Compatible with Drupal 9, 10 and 11
  • Minimalist, easily customizable black-and-white UI
  • Responsive layout, optimized for mobile and tablet
  • Bootstrap integration: responsive grid and UI components (built on FlexiStyle Bootstrap)
  • Latest Font Awesome icons
  • Global settings: system fonts, Google Fonts, icon fonts, custom body classes
  • Easy-to-use layout and appearance settings
  • Follows accessibility best practices
